# Verification fixtures

Fixtures are redacted, replayable evidence only. Keep secrets, API keys, cookies, and personal data out of this directory. Each passed source must include a request, representative response, retrieval/evidence note, and SHA-256 recorded in `manifest.json`; the response must be checked against the exact URL and field semantics.

All current Ondo and DIA records are `pending`. PWM/Perplexity is discovery and review support, never a production numeric source. Do not mark a source passed until identity coverage, token-versus-underlying semantics, pagination, failure behavior, historical definitions, and redistribution/static-artifact licensing are verified.
